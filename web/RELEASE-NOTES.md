# HV-Planer V6.66

## Externe logische Quellen

- Beliebig viele externe Quellen definierbar, z. B. `HAK / EVU`, `Zählerschrank D02 40 A` oder eine zweite unabhängige Zuleitung.
- Quellen belegen keine TE und haben bewusst keinen Bezug zu einem zweiten gezeichneten Schrank.
- Jede Quelle stellt L1, L2, L3, N und PE bereit und kann direkt mit Geräteeingängen verknüpft werden.
- Mehrere unabhängige Zuleitungen können innerhalb eines Verteilers logisch zusammengeführt werden.
- V6.65-Projekte mit freier Einspeisungsbezeichnung werden beim Laden automatisch in eine externe Quelle migriert.
